# CC5212 — Procesamiento Masivo de Datos

Repositorio de laboratorios de **Jiale Chen** para el ramo **CC5212 — Procesamiento Masivo de Datos** de la Universidad de Chile, semestre primavera de 2026.

Incluye código, ejercicios y resultados relacionados con el procesamiento de grandes volúmenes de datos y los sistemas distribuidos.

## Temas abordados

- Procesamiento de texto y conteo de palabras.
- Comunicación distribuida con Java RMI.
- Almacenamiento y procesamiento con Hadoop, HDFS, Pig y Spark.
- Procesamiento de flujos de datos con Kafka.
- Indexación y búsqueda con Elasticsearch.
- Procesamiento de grafos y PageRank con Giraph.
- Bases de datos NoSQL con Cassandra.

## Organización

Los trabajos se organizan en carpetas por laboratorio, con sus implementaciones y archivos de apoyo. El contenido se actualiza a medida que avanza el curso.
